## 1. 本轮交付

| 范围 | 已落地结果 |
|---|---|
| 桌面实验室 | 从0月持续月进，默认1月；参数只影响未来，政策作用当前城市；配置方案与完整运行存档分离；当前现金立即反映政策，历史月报不改写 |
| 政策 | 限招/限裁在劳动力匹配前生效；N月恰好覆盖N次结算；退税受实缴及预算约束，保留原交易；公务员雇佣增加持续岗位计划，后续承担工资；救济按失业群体比例 |
| 交易 | 本地分单真实成交，收款不再受收款方余额限制；原料金额单位一致；需求加权归一化，库存目标按真实销量计算；工资追赶物价调整后的基准 |
| 补给与投资 | 市政采购原料形成市政所有库存，企业领用款回到市政，避免同批原料重复付给外部；无资金不交货；可取消资本支出先留运营预算，首月和亏损期暂停 |
| 账目与人口 | 欠薪按雇主/居民记录并实际偿还；财政月报含月间政策与建设净流；总居民、劳动力及消费等价区分；自然变化年率换月率，正负变化及小数余量生效 |
| 地图 | 完整占地/旋转/道路/预算校验；真实付款、次月完工；住房独立于农业岗位；工坊与集市增加设施及岗位；维护欠款、拆除/迁址限制及唯一编号 |
| 运行保护 | 操作在副本核对后提交；重复请求只生效一次；存档版本与配置分离，拒绝不完整历史及损坏月报；保存保留上一份备份，加载失败保留当前城市 |
| 文档 | README重写，旧说明归档；更新导航、用工模型状态、中文changelog；旧审计保留为当时事实 |

主要代码入口：`backend/industry_api.py`、`game_api.py`、`backend/systems/v21/industry_economy.py`、`industry_state.py`、`map_economy.py`、`map_geometry.py`、`tools/lab_session.py`、`tools/economy_lab.py`。

- 全量测试：`python -m pytest -q`，最终完整复核 **861 passed in 12.79s**。
- 桌面：`python -m scripts.check_industry_gui`，最新**11项真实Tk事件循环及控件操作检查通过**。含连续月进、施策即时显示、运行存读后下一月逐项一致、坏历史拒载、非法输入、关闭工作线程；未冒充操作系统鼠标验收。
- 浏览器：`python -m scripts.check_single_city_browser`，独立Chromium实际点击新开局、种子、地图预览、旋转建工坊、月进完工、补贴、限裁、保存、读取、再月进及刷新；**6组交互检查通过，页面错误0**。读取后完整月报与未中断路径一致。
- 浏览器使用临时端口、独立服务和临时存档，不访问现有城市。截图已实际查看；证据和截图位于`artifacts/single-city-browser-2026-10-16/`。
- 桌面证据位于`artifacts/industry-gui-check/evidence.json`；全量差异格式检查使用`git diff --check`。

原有“120月无操作必须耗尽原料”的测试已改为核对有限资源真实减少与守恒，因为原料单位修正后，不应把预设崩溃月份当成正确结果。

## 3. 长期实验与未完成门槛（已重新定位）

按 2026-10-16 用户明确决定：**经济崩溃首先判定为玩家不作为或错误作为的结果，不视为经济内核的 bug；120 月全面健康门槛不再作为开发目标。** 经济内核只保证技术正确性（守恒、月结合法、原料资金真实流动、存档原子提交），不承担"经营一定能活"。

测试通过、现金守恒、单个行业仍存续均不能替代"经营是否健康"——后者是玩家的事，不在验收口径内。详细设计与触发器参见 [游戏最终设计要点与校长修正-2026-10-16](../03_设计规范/游戏最终设计要点与校长修正-2026-10-16.md)。

历史策略数据保留如下供参考（不作为后续必须达成的目标）：

|---:|---:|---:|---:|---:|

| 36 | 1281 | 0 | 630730.65 | 2579179.55 |

较稳策略：外部订单本地分成0、政府月采购5000 CR、利润税倍率2，按近月消耗采购原料至约3月储备，保留国库2万CR；每次采购都检查真实预算与结果。45次采购全部成功，累计实际支付3595590.89 CR，其中市政原料有后续真实转售回款，该总支付不是净财政损失；现金残差持续为0，没有隐藏注资。第120月失业率约33.4%，仍属于"经营恶化但城市未崩"区间，由后续玩家按经济运行情况自行判断是否触发"市长下台"事件。

另一冲击实验：第36月就业1302，冲击后第42月1148，恢复条件后第48月1396，该案例短期恢复成立；第120月又降到758，仍属恶化区间。没有以局部反弹冒充长期通过。

详细场景、检查点与动作见[长期策略证据](单城修复长期策略证据-2026-10-16.json)。失败策略和资本支出诊断保存在`artifacts/strategy-diagnosis-2026-10-16/`，不覆盖最初评估证据。

## 4. 继续开发入口

按 2026-10-16 用户最新决定调整后的优先级，120 月长期经济校准从入口中删除，新增"游戏结束机制"与"世界地图"作为新入口：

| 顺序 | 剩余工作 | 验收要求 |
|---|---|---|
| 1 | 24 个月玩家试玩与月报解释 | 核对新人能否理解扩产、救助、民生之间的取舍；当前自动化不能代替实际玩家体验判断 |
| 2 | **游戏结束机制：月初报告极度异常 → 市长下台** | 见[游戏最终设计要点与校长修正-2026-10-16 §3](../03_设计规范/游戏最终设计要点与校长修正-2026-10-16.md)；实现触发器、宽限期、议会事件链、任期回顾界面 |
| 3 | **世界地图渲染层** | 见[同上 §2](../03_设计规范/游戏最终设计要点与校长修正-2026-10-16.md)；5—8 NPC 城市节点、连线、距离、容量、状态、风险显示；NPC 城市经济统计后台运行 |
| 4 | 住房入住/产权与世界接入 | 当前住房具备真实容量和投资，完整逐户租售、迁移与跨城合同仍是后续开发 |
| 5 | 金融、贸易、公共系统和政治 | 按单城基础→贷款→关键商品/运输→少量对手城市（含世界地图）→公共系统顺序扩展，不将独立规范模块声称为已接入游戏 |

旧存档缺少新增债权、人口余量、市政库存所有权等字段会被明确拒绝；不要直接覆盖原存档。当前未自动迁移旧城市，也未提交或推送Git。
