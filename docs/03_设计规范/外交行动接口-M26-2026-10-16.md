## 1. 设计目标

**M26 = 把 NPC 城市从"旁观者"变成"可交互对手"。**

M25 让玩家看到 NPC 城市的节点 + 友好度，但友好度是只读的（M25 阶段固定 50）。M26 让玩家主动采取 5 类外交手段改变友好度：

| 行动 | 友好度影响 | 玩家意图 |
|---|---|---|
| 贸易协议 | +1/月 | "我们做朋友吧" |
| 援助 | +ceil(amount/100) | "我送你一些物资" |
| 开放移民 | +3 | "我们互相欢迎人口流动" |
| 公开声明 | ±2 | "我代表城市发表声明" |
| 征收关税 | -10 | "我不喜欢你，制裁你" |

玩家外交目的不是只能"加好感"——也可以"制裁"，这给游戏策略空间。

## 2. 游戏体验：玩家如何与 NPC 互动

### 场景 1：发展友好关系

玩家想跟碧涛港（商业型）建立贸易协定：

```
步骤：
1. 打开 http://127.0.0.1:8876/world
2. 点击碧涛港节点（蓝色）
3. 右侧 NPC 详情面板展开
4. 看到「外交行动」按钮组：贸易协议 +1/月 / 援助 / 开放移民 +3 / 公开声明 +2/月 / 征收关税 -10
5. 点击「贸易协议」→ 友好度 50 → 51
6. 详情面板「友好度 49 / 100」（注：trade_agreement + aid 已发多次，这里最后为 49 是计算后的口径）
8. 下方「外交行动历史」显示：「✓ trade_agreement (月 0) +1 / ✓ aid (月 0) +6 / ✓ statement (月 0) +2 / ✓ tariff (月 0) -10」
9. 地图上碧涛港与玩家城之间的连线颜色按友好度变化
```

### 场景 2：援助大金额

玩家想援助 5000 CR 给铁壁关：

```
1. 点击铁壁关节点
2. 点击「援助」按钮 → 弹出输入框
3. 输入 5000 → 友好度 +ceil(5000/100)=50 → 上限 100
4. 友好度 50 → 100（钳到 100）
5. 「外交行动历史」记录：「aid (月 0) +50」
```

### 场景 3：拒绝违规操作

```
1. 玩家对同一城市第 4 次点「贸易协议」
2. 友好度 detail 显示：「✗ 拒绝：本月已用尽：签订贸易协议（上限 3 次/月）」
3. 友好度数字不变
```

## 3. 5 类外交行动

### 3.1 trade_agreement（贸易协议）

| 字段 | 值 |
|---|---|
| 友好度变化 | +1/月（持续） |
| 月限 | 3 次 |
| 冷却 | 无 |
| 可见等级要求 | 1（认识级，友好度 > 20） |
| 现金成本 | 0 |

> 玩家与 NPC 签订长期贸易协议。后续每月友好度自然增长，但贸易本身不实际产生现金流（M26 阶段）。

### 3.2 aid（援助叙事）

| 字段 | 值 |
|---|---|
| 友好度变化 | +ceil(金额/100) |
| 月限 | 1 次 |
| 冷却 | 2 月 |
| 可见等级要求 | 0（陌生人级即可） |
| 现金成本 | 玩家输入的"叙事规模"（不实际扣款） |

> 玩家向 NPC 政府承诺援助。**aid 是叙事动作**：玩家输入的金额只用作计算友好度变化，不实际从 GOV cash 扣款（理由：aid 真实成本会引入跨城现金流，破坏 IndustryEconomy 守恒；改为叙事友好度信号）。

### 3.3 immigration_open（开放移民）

| 字段 | 值 |
|---|---|
| 友好度变化 | +3 |
| 月限 | 2 次 |
| 冷却 | 1 月 |
| 可见等级要求 | 0 |
| 现金成本 | 0 |

> 玩家放宽对 NPC 居民的人口流动限制。友好度小幅增长。

### 3.4 statement（公开声明）

| 字段 | 值 |
| |---|
| 友好度变化 | ±2（玩家可传 note 决定正负） |
| 月限 | 1 次 |
| 冷却 | 无 |
| 可见等级要求 | 0 |
| 现金成本 | 0 |

> 玩家对全国发表公开声明。低成本、quick win。

### 3.5 tariff（征收关税）

| 字段 | 值 |
|---|---|
| 友好度变化 | -10 |
| 月限 | 1 次 |
| 冷却 | 1 月 |
| 可见等级要求 | 0 |
| 现金成本 | 0 |

> 玩家对 NPC 商品征收关税。友好度大幅下降（-10），对方视玩家态度不当。这是 M26 唯一可能让友好度下降到 0 的快速路径（tariff + cooldown 月 + max_per_month=1 让连按 5 次友好度从 50 → 0）。

## 4. 限制与冷却

### 4.1 max_per_month

每个 action_key 每月最多触发 `max_per_month` 次。超出会返回 "拒绝：本月已用尽：<label>（上限 N 次/月）"。

例如 trade_agreement max_per_month=3，玩家第 4 次点会被拒。

### 4.2 cooldown_months

部分 action 有冷却期（cooldown_months）：上次成功触发后，N 个月内不能再次触发。

例如 tariff cooldown_months=1，玩家第 1 月触发后，第 2 月再触发会被拒（"冷却中：剩 1 月"）。

### 4.3 requires_visibility

action 要求玩家对该 NPC 城市的可见等级 ≥ `requires_visibility`。

例如 trade_agreement requires_visibility=1，玩家友好度 ≤ 0 时无法触发（"拒绝：可见等级不足"）。

这是设计上有意为之的——**陌生人不会跟你做生意**。

### 4.4 friendly 0-100 钳位

`adjust_friendliness()` 把友好度钳到 [0, 100] 范围。多次 tariff 后 friendly 钳到 0；多次 trade 后 friendly 钳到 100。

### 5.2 数据契约 `data/diplomacy_actions.json`

```jsonc
{
  "_comment": "M26 玩家外交行动契约：5 类行动 + 友好度影响公式 + 限制。",
  "actions": {
    "trade_agreement": {
      "label": "签订贸易协议",
      "description": "...",
      "cost_cr": 0,
      "monthly_cost_cr": 500,
      "friendliness_delta_per_month": 1,
      "cooldown_months": 0,
      "max_per_month": 3,
      "requires_visibility": 1
    },
    // ... 4 条其他规则
  }
}
```

字段含义：
- `cost_cr`：`0` = 固定成本 0；`"user_supplied_narrative"` = 由玩家输入但仅作文本信号
- `monthly_cost_cr`：预留字段，未来 M27 可能加持续成本（M26 未启用）
- `friendliness_delta_per_month`：单月友好度变化（除 aid 用 ceil(amount/100)）
- `cooldown_months`：上次成功到下次允许之间的间隔
- `max_per_month`：每月上限
- `requires_visibility`：最小可见等级（0-4）

### 5.3 DiplomacyActionValidator

```python
def validate(self, action, current_month, visibility, history, player_cash_cr) -> (bool, str, int):
    if action.action_key not in self.actions:
        return False, '未知行动', 0
    cfg = self.actions[action.action_key]
    # 1. 可见等级
    if visibility < cfg.requires_visibility:
        return False, '可见等级不足', 0
    # 2. 月内次数
    same_month = [h for h in history if h.action_key == cfg.key and h.month == current_month]
    if len(same_month) >= cfg.max_per_month:
        return False, '本月已用尽', 0
    # 3. 冷却期
    cooldown = [h for h in history if h.action_key == cfg.key
                and current_month - h.month < cfg.cooldown_months]
    if cooldown:
        return False, '冷却中', 0
    # 4. aid 校验：金额 ≥ 100
    if action.action_key == 'aid' and action.cost_cr < 100:
        return False, '援助金额至少 100 CR', 0
    # 5. 计算友好度
    if action.action_key == 'aid':
        delta = max(1, ceil(action.cost_cr / 100))
    else:
        delta = cfg.friendliness_delta_per_month
    return True, '', delta
```

### 5.4 DiplomacySystem.apply_player_action

```python
def apply_player_action(self, action, current_month, player_cash_cr):
    validator = DiplomacyActionValidator()
    visibility = self.get_visibility(action.target_city_id)
    ok, reason, delta = validator.validate(
        action=action, current_month=current_month,
        visibility=visibility, history=self._player_actions_history,
        player_cash_cr=player_cash_cr)
    if not ok:
        record = DiplomacyAction(..., success=False, reject_reason=reason)
        self._record_action(record)
        return False, reason, record
    # 调 adjust_friendliness
    self.adjust_friendliness(self.player_city_id, action.target_city_id, delta, ...)
    record = DiplomacyAction(..., success=True)
    self._record_action(record)
    return True, '', record
```

## 6. 核心约束：叙事优先，不破坏经济守恒

**M26 最重要的设计决策：玩家外交行动不实际扣款 / 不实际转账。**

为什么？

1. **aid 真实成本会引入跨城现金流**：玩家城市 GOV cash → NPC GOV cash。IndustryEconomy 没有这种转账操作，强行做会破坏 `cash` 守恒校验。
2. **关税真实成本**会涉及"对 NPC 商品征税"——但 NPC 城市的"商品"在 M26 阶段还未与玩家城市建立贸易网，无从征收。
3. **设计意图**：M26 是**关系层**，不是**经济层**。友好度变化是叙事信号；真实贸易/援助留给 M27（NPC-NPC 贸易网）+ M28（行业情报）。

代价是**叙事简化**：援助 5000 CR 实际上没真的从玩家账户扣款。但这个简化换来**守恒完整性**——这是核心约束的合理 trade-off。

后续路线：M27 阶段会引入真实贸易，那时 aid 可以改为真实 GOV→NPC GOV 转账（增加 `IndustryEconomy.transfer_to_npc()` 方法，仍保持守恒）。

## 7. 边界与限制

- **不能对自己发起外交行动**：target_city_id == player_city_id 返回 400。
- **不能修改与对手对话**：DiplomacySystem 仅维护 NPC 之间关系；玩家城市互相之间没外交概念。
- **看不到玩家城市自己的友好度**：DiplomacySystem.relation_with_player(player_city_id) 是 self-relation，没意义。`/api/world/diplomacy_actions/{player_id}` 会返回空（因为历史里没 target_city_id == player_id 的项）。
- **aid 最低 100CR**：避免 spam 友好度（每次 +1 友好度）。
- **玩家下台后无法发起外交**：返回 409（与 advance 行为一致）。
- **存档兼容**：`_player_actions_history` 保留最近 200 条；存档只存 WorldGame 单例（不直接持久化到 IndustryGame.save）。M27 阶段会让存档恢复外交状态。

## 9. 后续路线

### M27：NPC-NPC 贸易网

5 座 NPC 城市互相交易，按距离/友好度产生月度贸易流，玩家可在世界地图上看到"贸易路线"叠加在关系连线上。这是 M26 援助"不实际扣款"的真正扩展——真实贸易。

### M27.1：真实援助转账

aid 改为真实 GOV→NPC GOV 转账：玩家城市 GOV cash 减，NPC 城市 cash 加。需要扩展 IndustryEconomy 引入 `transfer_to_npc(target_city_id, cash_cr)` 方法，绕过守恒校验。

### M28：行业情报

玩家可向友好度 ≥ 3（盟友级）的 NPC 城市派遣"商业间谍"获取完整 last_report（不脱敏）。这是 M25 后台设计中的"信息差"玩法扩展。

### M29：世界事件

随机世界事件（瘟疫/丰收/战争）按距离影响周边城市友好度+经济指标。事件来自 WorldGame.world.month 推进时触发。

### M30：长期政治

NPC 城市联盟/敌对关系，玩家可加入任一阵营，影响全局贸易格局与外交决策。
