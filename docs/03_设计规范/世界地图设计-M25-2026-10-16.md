## 1. 目标与定位

**M25 = 把"地图上的 5 座 NPC 城市"从口号变成可玩模块。**

2026-10-16 校长修正明确要求：

> NPC 城市后台统计运行，但世界地图必须画出来；经济崩溃首先判定为玩家责任，不视为内核 bug。

M25 完成两件事：

1. **后台**：5 座 NPC 城市各自跑一套完整的 `IndustryEconomy`，与玩家城市**同内核同精度**，不是简化近似。
2. **前台**：`/world` 独立 Web 页面，纯 SVG 复古地图背景，5 节点 + 10 连线 + 玩家城金色光晕 + 罗盘玫瑰 + 山脉河流装饰。

后续阶段（M26+）会让玩家通过**外交行动**（贸易协议、援助、关税、移民政策）主动改变友好度，把 NPC 城市从"旁观者"变成"可交互对手"。M25 是基础设施层。

## 2. 用户视角

打开 `http://127.0.0.1:8876/world`，玩家看到：

- **顶部**：BIPOLE 双极·世界地图品牌条
- **中央**：国家大陆地图，5 座 NPC 城市节点 + 玩家城节点（金色光晕）
- **节点间**：10 条连线，颜色按友好度（红/黄/绿渐变）+ 粗细 + 透明度
- **右上**：罗盘玫瑰（指北 N）
- **左上**：风玫瑰（风向标记）
- **底部装饰**：山脉 + 河流
- **右侧**：NPC 城市详情面板（默认"点击节点查看"提示）
- **底部**："推进 1 个月 →" 按钮 + 月份状态行

玩家操作：

1. **点击 NPC 节点** → 右侧详情面板更新为该城市的脱敏视图
2. **查看友好度、可见等级、解锁字段**
3. **查看 AI 市长最近动作**（最近 6 条）
4. **推进 1 个月** → 5 座 NPC 城市 AI 决策 + 玩家城市同步结算

## 3. 参数三层分离

| 层级 | 数据类 | 共享范围 | 例子 |
|---|---|---|---|
| **世界级** | `WorldState` | 5 城市共享 | 5 城市坐标、距离矩阵、参考通胀、参考消费 |
| **国家级** | `DiplomacySystem` | 玩家城市视角共享 | 友好度、贸易量、关系事件 |
| **城市级** | 每座 `IndustryEconomy` | 每城独立 | scenario、人口基数、行业容量、税率、市长决策 |

**世界级** 数据类 `WorldState` + `CityNode` 在 `backend/systems/v21/world_state.py` 定义，单一数据源 `data/world_map.json`。玩家看不到这个层级的修改入口——它是"地图本身的属性"。

**国家级** 数据类 `DiplomacySystem` 在 `backend/systems/v21/diplomacy.py` 定义，挂在 `WorldGame` 单例上。友好度矩阵 5×5，玩家城市与 5 NPC 各有一个分数，每个月底按"距离/事件/贸易"重新计算（M25 阶段只初始化默认值，后续 M26 阶段允许玩家行动改变）。

**城市级** 每座 NPC 城市是一个独立 `IndustryEconomy` 实例，从 `data/npc_mayor_profiles.json` 读取 archetype + 偏好配置，启动时一次性构建。它与玩家城市的 `IndustryEconomy` 使用完全相同的七行业内核（AGR/IND/SRV/CHU/BNK/MAG/GOV），配置不同。

## 4. 5 座 NPC 城市 archetype

| ID | 中文名 | archetype | 配色 | 行业偏好 | 关键差异 |
|---|---|---|---|---|---|
| `agricultural_town` | 禾谷镇 | 农业型 | 绿色 `#8b9d3f` | AGR +++ | 人口基数大、失业敏感、税率保守 |
| `industrial_city` | 河湾镇 | 工业型 | 赭红 `#a87878` | IND +++ | 行业危机敏感（连续 3 月亏损触发 AI 动作） |
| `commercial_port` | 碧涛港 | 商业型 | 蓝色 `#507ba0` | SRV +++ | 人口基数小、月营业额高 |
| `magic_academy` | 辉月学城 | 魔法型 | 紫色 `#9050a0` | MAG +++ | BNK/MAG 双线、税率较高（学术税） |
| `mining_border` | 铁壁关 | 矿业边境型 | 棕色 `#6b5238` | IND/CHU ++ | 现金敏感、人口外流风险 |

每座 NPC 城市的 `MayorPreferences` 字段（见 `data/npc_mayor_profiles.json`）：

```jsonc
{
  "id": "agricultural_town",
  "name_cn": "禾谷镇",
  "archetype": "agricultural_town",
  "initial_population": 28000,
  "industry_focus": {
    "AGR": 1.8,  // 偏好权重，加权打分
    "IND": 0.6, "SRV": 1.0, "CHU": 0.9,
    "BNK": 0.5, "MAG": 0.4, "GOV": 0.7
  },
  "tax_rate_preference": 0.08,  // AI 税率会向这个值收敛
  "hiring_bias": "defensive",   // defensive / aggressive / neutral
  "ai_decision_freq": 2         // 每月决策 1—2 次
}
```

`archetype` 决定开局 7 行业就业分布（来自 `IndustryEconomy.presets`），`industry_focus` 决定 AI 决策的偏好加权。

## 5. AI 市长决策模型

每座 NPC 城市在 `WorldGame.advance()` 调用时按顺序执行：

```text
1. NPC 城市 A 决策 → 执行动作 → 写入 _commands
3. NPC 城市 B 决策 → ...
5. 玩家城市 IndustryGame.advance() → ...
```

**综合指数公式**：

```
composite = 0.4·employment_rate
          + 0.3·fiscal_health        // 政府现金 / 居民消费月数
          + 0.2·unpaid_penalty       // (1 - 累计欠薪/应付工资)
          + 0.1·population_stability // 1 - |人口变化率|
```

**候选动作**：

| 动作 | 效果 | 是否允许 NPC |
|---|---|---|
| `adjust_tax_rate` | 改变税率（步长 0.02），向 `tax_rate_preference` 收敛 | ✅ |
| `subsidy_industry` | GOV → 行业现金 | ✅ |
| `hire_civil` | 雇佣失业者入公务员 | ✅ |
| `pardon_welfare` | 救济失业池 | ✅ |
| `limit_hire` | 限时 N 月禁止某行业新进 | ✅ |
| `limit_layoff` | 限时 N 月禁止某行业裁员 | ✅ |
| `purchase_external` | 市政采购外部现金/原料 | ✅ |
| `adjust_base_param` | 调整基础参数（生活成本、家庭人口等） | ❌ 禁止 |
| `transfer_cash` | 跨城资金流 | ❌ 禁止 |
| `borrow_loan` | 借贷 | ❌ 禁止 |
| `add_industry_capacity` | 新建/拆除建筑 | ❌ 禁止 |

**决策流程**（每 NPC 城市每个月）：

1. 计算综合指数 `composite`
2. 列出所有可行动作，过滤掉预算不足的
3. 对每个动作计算"预期增益"：`Δcomposite × industry_focus[行业]`
4. 选 1—2 个最高分的动作
5. 写入 `IndustryEconomy._commands` 历史

玩家可在 NPC 详情面板看到这些动作（最近 6 条），含 `reason` 字段摘要（如"GOV 现金偏低，向偏好税率收敛 +0.02"）。

## 6. 友好度脱敏机制

友好度 0—100，按 0/21/41/61/81 切分 5 级可见等级：

| 友好度 | 等级 | 解锁字段（附加） |
|---|---|---|
| 0—20 | Lv.0 陌生人 | 仅城市名 + 千人量级人口 |
| 21—40 | Lv.1 认识 | + 百人量级劳动力 |
| 41—60 | Lv.2 友好 | + 7 行业就业 + 财政（七行业月营业额 + 政府现金） |
| 61—80 | Lv.3 盟友 | + 月产（粮食/原料库存） |
| 81—100 | Lv.4 完全开放 | 全部字段（月贸易额、政府现金流覆盖月数） |

**脱敏实现**（`backend/systems/v21/world_view.py` `get_city_view`）：

1. 读取友好度 → 计算 `visibility_level`
2. 从 `last_report` 取所有字段
3. 按可见等级过滤：等级不足的字段设为 `None`
4. 前端 `world_detail.js` 渲染时 `None` → 显示「？？？」占位 + `.row.locked` 灰化

**为什么显示「？？？」而不是隐藏？**

让玩家知道"还有更高等级才能看到的字段"，信息差是后续外交/贸易玩法的入口。如果直接隐藏，玩家无法判断 NPC 是否藏着秘密。

## 7. 世界地图渲染层

`frontend/world.html` + `frontend/js/world_map.js` 纯 SVG 渲染，**不依赖任何外部美术资源**（除 `emblem.svg` 品牌图标）。

**SVG 分层**（从底到顶）：

1. **底色** `<rect 0,0,1000,700 fill=radialGradient>` — 米黄径向渐变
2. **旧纸纹理** `<rect filter=feTurbulence>` — fractalNoise + 棕色 colorMatrix
3. **山脉** `<path>` × 7 — 北侧山脊线
4. **河流** `<path>` — 中部蜿蜒河道
5. **装饰元素**（`#decor` g）
   - 罗盘玫瑰：右下 `<g translate(900,620)>`，4 向 + 8 角小方块
   - 风玫瑰：左上 `<g translate(80,100)>`
   - 装饰花边：双层 `<rect>`（实线 + 虚线）
6. **连线** `<line>` × 10 — 友好度渐变（红 `#a13d2b` / 黄 `#d4a537` / 绿 `#2c7a3d`）
7. **城市节点**（`#nodes` g，每个 `<g class="city-node" data-city-id="...">`）
   - 玩家城：金色光晕 `<circle filter=feGaussianBlur>` + 内圈金色描边
   - NPC 城：实心圆 `<circle>` 按 archetype 配色 + 黑色描边
   - 城市名：`<text>` 中下方（粗体 + 描边以保证对比度）
   - archetype 副标题：`<text>` 上方（斜体小字）

**交互**：

- 节点 `<g>` 设 `cursor: pointer` + `onclick=window.onCityClick(city_id)`
- 点击 → `world_main.js` → `GET /api/world/cities/:id` → 渲染详情面板
- 推进按钮 → `POST /api/world/advance` → 重渲染

**viewport**：SVG 用 `viewBox="0 0 1000 700"`，CSS 锁死高度 560px + `flex:0 0 560px`，避免被全局 `100dvh` 撑高。

## 8. REST 接口

`backend/world_api.py` 三个端点：

| 方法 | 路径 | 用途 | 返回 |
|---|---|---|---|
| GET | `/api/world/state` | 地图概览 | 5 城市精简视图 + 友好度矩阵 + 月份 |
| GET | `/api/world/cities/:id` | 单城市脱敏详情 | 友好度/可见等级/锁定字段/AI 最近动作 |
| POST | `/api/world/advance` | 推进 1 月 | 新月份 + 5 城市 last_report 摘要 |

`GET /api/world/cities/:id` 对**玩家城市**返回 409，避免误读玩家自己的行业经营页面。

`WorldGame` 单例通过 `backend.systems.v21.world_game.get_world_game()` 获取，启动时初始化玩家城市（注入现有 `IndustryGame`）+ 5 NPC 城市 + DiplomacySystem。

## 9. 边界与限制

- **经济崩溃 = 玩家责任**：不在经济内核层面追求 120 月长期健康门。M24 触发器独立判断玩家城市是否极度异常，玩家城市经济出问题不算 bug，是游戏内容。
- **AI 市长不调基础参数**：`living_cost_cr` / `household_consumption_size` / 通胀率等是世界级或场景级参数，AI 改这些相当于"作弊"。M25 严格禁止。
- **AI 市长不跨城资金**：`transfer_cash` 不在候选动作中，防止 NPC 城市互相"输血"。
- **AI 市长不借贷/不建设**：`borrow_loan` / `add_industry_capacity` 不在候选动作中，避免 NPC 城市场偷偷盖楼盖栋让玩家觉得"凭什么他能建我不能"。
- **友好度 M25 阶段只读**：玩家**不能**主动改变友好度，但 NPC AI 也不会主动加/减友好（除非贸易事件）。M26 阶段会增加玩家外交行动接口。
- **NPC 城市间无贸易**：M25 阶段 5 NPC 城市互相不交易，只各自跑内核。这是 M25 的简化假设，M26+ 阶段会增加 NPC-NPC 贸易网。

## 11. 后续路线

### M26：外交行动接口（玩家主动改友好度）

- 玩家城市向 NPC 城市发起贸易协议（每月贸易额上限提升）
- 援助（一次性 GOV → NPC GOV 现金转账，友好度 +）
- 关税（限制某 NPC 城市的月贸易额，友好度 -）
- 移民政策（开放/限制人口流入，友好度 ±）
- 公开声明（无成本外交信号，每月 1 次）

### M27：NPC-NPC 贸易网

5 座 NPC 城市互相交易，按距离/友好度产生月度贸易流，玩家可在世界地图上看到"贸易路线"叠加在关系连线上。

### M28：行业情报

玩家可派遣"商业间谍"获取 NPC 城市的脱敏字段（友好度阈值），或在友好度足够高时直接读取完整 last_report。

### M29：世界事件

随机世界事件（瘟疫/丰收/战争）按距离影响周边城市，AI 市长决策受事件影响。

### M30：长期政治

NPC 城市联盟/敌对关系，玩家可加入任一阵营，影响全局贸易格局与友好度计算。
