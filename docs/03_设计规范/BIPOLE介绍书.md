## 1. 游戏概述

**BIPOLE**（双极城市纪事）是一款浏览器 2D 网页制魔导城市经营游戏。玩家是**城市市长**，按月推进经济，与 5 座 NPC 城市（禾谷镇 / 河湾镇 / 碧涛港 / 辉月学城 / 铁壁关）互动；NPC 城市有 AI 市长，会自主决策。

**核心张力**：玩家是**经济崩溃的第一责任人**（校长修正 2026-10-16 明确），不在经济内核层面追求 120 月长期健康门。崩溃不是 bug，是**游戏内容的一部分**——市长会被触发器判定下台，玩家可以选择**新城市重启**或**读取存档**。

**游戏世界观**：单城双行业体系（玩家城市）+ 五城 NPC 关系网。玩家是中央大陆的一座新城，与周边 5 座文化/经济重心各异的城市互动。

## 2. 参数分层：三层数据架构

| 层级 | 数据类 | 谁共享 | 例子 |
|---|---|---|---|
| **世界级** | `WorldState` | 5 城市共享 | 5 城市坐标、距离矩阵、参考通胀、参考消费 |
| **国家级** | `DiplomacySystem` | 玩家城市视角共享 | 友好度、贸易量、关系事件 |
| **城市级** | 每座 `IndustryEconomy` | 每城独立 | scenario、人口基数、行业容量、税率、市长决策 |

**设计要点**：
- **世界级与国家级**在 `data/world_map.json` / `data/diplomacy_actions.json` 等数据契约外置，玩家可调。
- **城市级**每座城市（玩家 + 5 NPC）独立 IndustryEconomy 实例，scenario 不同。
- **跨层耦合**严格受限：WorldState 不直接读写 IndustryEconomy，DiplomacySystem 通过 adjust_friendliness 而非 cash。

## 3. 核心玩法循环

```text
玩家每月操作：
1. 在地图 / 上点合法地块 → 放建筑 → 调 IndustryEconomy.add_industry_capacity（增加 IND 容量）
2. 在 /industry 上选行业 + 调税率 / 补贴 / 救济 → 调 IndustryEconomy.mayor_command
3. 在 /world 上点 NPC 城市 → 选外交行动 / 派间谍 → 调 DiplomacySystem.apply_player_action / Espionage
4. 点"月进 →" → IndustryGame.command('advance', months=1)
       ├─ city.advance()  # 月结副本+校验+提交
       ├─ EconomicTrigger.evaluate(last_report)  # M24 触发器只读
       └─ WorldGame.advance_npc_only(months)  # 调 NPC AI 决策 + NPC 城市 advance + M27 贸易流
5. 检查 last_report（行业就业、政府现金、失业率、累计欠薪、人口）
6. 检查 EconomicTrigger.is_game_over → 若 True：市长下台横幅 + 推进按钮置灰
```

## 4. 经济内核 — 七行业标准交付包

**这是 BIPOLE 整个游戏的经济基础**。

### 4.1 七行业

| 行业 | 中文 | 角色 |
|---|---|---|
| AGR | 农业 | 粮食产出 + 容纳大量就业 |
| IND | 工业 | 成品产出 + 月营业额主力 |
| SRV | 服务业 | 商业服务 + 高容纳 |
| CHU | 教堂/宗教 | 受 offerings_cr 影响 + 容纳稳定 |
| BNK | 银行 | 现金管理 + 低就业 |
| MAG | 魔法/学术 | 高技能 + 低就业 |
| GOV | 政府 | 公务员（玩家市政指令雇人） |

### 4.2 关键经济信号（玩家能看到）

| 字段 | 通俗说 |
| --- | --- |
| 总人口 | 城市规模 |
| 劳动力 | 实际可参与就业的人数（按比例从总人口派生） |
| 失业率 | 失业人数 / 劳动力 |
| 七行业月营业额 | 城市经济活力指标 |
| 政府现金 | 国库够发几月工资？ |
| 累计欠薪 | 工资拖欠规模 |
| 月贸易额 | NPC-NPC 之间的总贸易 |

### 4.3 设计要点

- **守恒校验**：`assert_invariants()` 校验 `cash + OCEAN == initial_total_cash`，每月必须对账
- **OCEAN 池**：虚拟外部资金池，玩家与 EXT 的资金流都走这里
- **EXT 现金与原料**：外部节点的可选装备（M26 阶段还没与玩家实质交互）
- **人口自然演化**：按世界银行 2022 出生率/死亡率弹性驱动，每月净人口变化同步更新
- **月进**（advance）= 真实推进所有经济参数；不是静态模拟，是"真实游戏循环"

## 5. M1-M2 地图建设 — 建筑放置与拆除/迁址

**这是 `/` 真游戏页面的核心玩法**。

### 5.1 6 类建筑

| 建筑 | 行业 | 效果 |
|---|---|---|
| workshop | IND | +40 IND jobs |
| market | SRV | +30 SRV jobs |
| row_house | AGR | +12 AGR 容纳 |
| apartment | AGR | +24 AGR 容纳 |
| park | — | 装饰 |
| town_hall | — | 不可建造（开局固定） |

### 5.2 建造规则

- 占地不能重叠、不能占用道路
- 黄色入口必须接道路（等距地图上的格点逻辑）
- R 旋转
- 建造投资真实付款 → 投资从 GOV cash 减
- **次月完工**才增加行业 capacity / 住房
- 地图点击查看 **建筑详情**面板

### 5.3 维护欠款

- 完工建筑从当月起承担维护
- 政府现金不足时维护欠付
- 维护欠款未清偿的建筑**不能拆除**

### 5.4 拆除与迁址（M2）

| 操作 | 限制 |
|---|---|
| **remove** 拆除 | 不能拆市政厅；不能让住房或在岗人员所需岗位不足；维护欠款未清偿不可拆 |
| **relocate** 迁址 | 校验新坐标不是水/桥/被占用；仅修改坐标，行业 jobs 不变 |

迁址是"视觉迁移"，不影响经济内核——这是为了让玩家重新规划地图。

## 6. M3-M5 行业经营 — 市政指令与折线图

**这是 `/industry` 页面的核心玩法**。

### 6.1 6 类市政指令（M-A1/A2）

| 指令 | 效果 |
|---|---|
| `subsidy_industry` | 政府 → 行业现金补贴 |
| `hire_civil` | 政府雇佣失业者入公务员 |
| `pardon_welfare` | 救济失业池 |
| `limit_hire` | 限时 N 月禁止某行业新进 |
| `limit_layoff` | 限时 N 月禁止某行业裁员 |
| `tax_amnesty` | 退还本行业本月已缴税 |

### 6.2 政策机制

- `_active_policies: {(target, kind): expiry_month}` 跨月生效
- 过期自动清理
- 限裁：方案 A（允许短期欠付，吸引力会同步下降）

### 6.3 21 个指标曲线图（M-A2 升级）

`/industry` 右侧 HTML5 canvas 折线图，覆盖 21 个指标：
- 总就业 / 总失业 / 政府现金 / 居民总储蓄
- 七行业总工资 / 总营业额 / 总现金
- 外部现金池 / OCEAN 池 / 外部原料
- 可劳动人口 / 家庭人口 / 月生活成本
- 财政月度结余 / 工资欠付累计 / 守恒残差
- IND 系列（就业 / 经营现金 / 亏损月数 / 销售额）

折线图月进追加一个点，与前一点连直线；底部「清空折线」按钮。

### 6.4 经营记录 / 政策流水

`_active_policies`（按行业|政策键索引到过期月份）和 `recent_mayor_actions`（最近 5 条指令）在 `/industry` 实时显示。

## 7. M-A2 AI 市长 — NPC 城市自动决策

**5 座 NPC 城市后台跑各自的 AI 市长**。

### 7.1 综合指数

```
composite = 0.4·employment_rate      # 就业率
          + 0.3·fiscal_health        # 政府现金 / 居民消费月数
          + 0.2·unpaid_penalty       # (1 - 累计欠薪/应付工资)
          + 0.1·population_stability # 1 - |人口变化率|
```

### 7.2 候选动作（每 NPC 城市每月 1-2 次）

| 动作 | 可调 |
|---|---|
| `adjust_tax_rate` | ✅（向偏好收敛，步长 0.02） |
| `subsidy_industry` | ✅ |
| `hire_civil` | ✅ |
| `pardon_welfare` | ✅ |
| `limit_hire` / `limit_layoff` | ✅ |
| `purchase_external` | ✅ |
| `adjust_base_param` | ❌ 禁止 |
| `transfer_cash` 跨城 | ❌ 禁止 |
| `borrow_loan` | ❌ 禁止 |
| `add_industry_capacity` 建筑 | ❌ 禁止 |

### 7.3 决策流程

1. 计算综合指数
2. 列出所有可行动作，过滤掉预算不足的
3. 对每个动作计算"预期增益"：`Δcomposite × industry_focus[行业]`
4. 选 1-2 个最高分的动作
5. 写入 IndustryEconomy._commands 历史

### 7.4 5 NPC 差异化配置

`data/npc_mayor_profiles.json`：

| NPC | archetype | industry_focus 加权 |
|---|---|---|
| 禾谷镇（agricultural_town） | 农业 | AGR +++ |
| 河湾镇（industrial_city） | 工业 | IND +++ |
| 碧涛港（commercial_port） | 商业 | SRV +++ |
| 辉月学城（magic_academy） | 魔法 | MAG +++ |
| 铁壁关（mining_border） | 矿业边境 | IND/CHU ++ |

每个 NPC 城市还有 `tax_rate_preference`（AI 调税率向其收敛）和 `hiring_bias`（defensive / aggressive / neutral）。

### 7.5 设计意图

让 5 NPC 城市**不同策略**，玩家能从外交情报中读出"谁在干什么"。

## 8. M25 友好度系统 — 5 级可见等级脱敏

**这是 `/world` 页面让玩家"看 NPC 城市"的核心机制**。

### 8.1 友好度 0-100

初始 50。玩家与 NPC 互动后上下调整（M26 外交 + M27 NPC-NPC 贸易 + M28 发现惩罚）。

### 8.2 5 级可见等级脱敏

| 友好度 | 等级 | 解锁字段 |
|---|---|---|
| 0-20 | Lv.0 陌生人 | 仅城市名 + 千人量级人口 |
| 21-40 | Lv.1 认识 | + 百人量级劳动力 |
| 41-60 | Lv.2 友好 | + 7 行业就业 + 七行业月营业额 + 政府现金 |
| 61-80 | Lv.3 盟友 | + 粮食月产/原料月产/库存 |
| 81-100 | Lv.4 完全开放 | 全部字段（月贸易额、GOV 现金覆盖月数） |

字段锁定时显示「？？？」占位，**让玩家知道"还有可探索的字段"**（信息差是后续外交/情报玩法的入口）。

### 8.3 自然可见 vs 主动获取

| 路径 | 自然可见 | 主动获取（M28） |
|---|---|---|
| 友好度 < 61 | 自然只看 5 级脱敏 | 即使派间谍也被拒 |
| 友好度 ≥ 61 | 自然看 Lv.3 + | 可以派间谍（M28） |
| 友好度 ≥ 81 | 自然看 Lv.4 + | 间谍也不再必要 |

## 9. M26 玩家外交 — 5 类主动外交行动

**这是玩家主动改变 NPC 友好度的接口**。

### 9.1 5 类行动

| 行动 | 友好度 | 限制 |
|---|---|---|
| **trade_agreement** 贸易协议 | +1/月 | 月限 3 次；需 visible ≥ 1 |
| **aid** 援助（叙事） | ceil(金额/100) | 月限 1 次；cooldown 2 月 |
| **immigration_open** 开放移民 | +3 | 月限 2 次；cooldown 1 月 |
| **statement** 公开声明 | ±2 | 月限 1 次 |
| **tariff** 征收关税 | -10 | 月限 1 次；cooldown 1 月 |

### 9.2 核心约束

**所有行动不实际扣款/转账**——仅修改友好度。理由：跨城现金流会破坏 IndustryEconomy 守恒，改为叙事友好度信号。

### 9.3 玩法举例

- 玩家想拉拢碧涛港：3 次/月 trade_agreement → 友好度 +3/月 → 3 月后从 50 → 59（仍友好级，但接近盟友）
- 玩家想升级到 Lv.3（盟友）：继续 trade_agreement 2 月 → 61（盟友）→ 解锁 M28 行业情报
- 玩家想惩罚铁壁关：1 次/月 tariff → 友好度 -10/月 → 5 月后从 50 → 0（最低陌生人）

### 9.4 UI 集成

`/world` NPC 城市详情面板新增「外交行动」按钮组（5 个按钮），每次成功/失败更新友好度数字与历史区。

## 10. M27 NPC-NPC 贸易网 — 自动月度贸易流

**这是让"世界活起来"的关键**。

### 10.1 触发条件

每 NPC 城市对在友好度 ≥ 30 时自动产生月贸易流。

### 10.2 月贸易额公式

```
volume = clamp(base × (friendly/100) × 1/(1+distance/100), 100, 5000) CR
```

参数（`data/npc_trade_routes.json`）：
- base_volume_per_month_cr = 1000
- friendliness_threshold = 30
- distance_factor_divisor = 100
- trade_friendliness_delta_per_month = 1
- min_volume_per_month_cr = 100
- max_volume_per_month_cr = 5000

### 10.3 友好度月增

双方友好度各自 +1/月（叙事信号，不实际转账）。

### 10.4 玩家-NPC 友好度不变

**只 NPC-NPC 自动变化**。玩家必须主动发起 M26 外交行动才能改变。

### 10.5 前端

地图叠加 6 条 NPC-NPC 蓝色虚线（`stroke-dasharray="5,3"`），中段标注月贸易额（取整 CR）。

### 10.6 示例

- 友好度 50, 距离 100 → volume = 1000 × 0.5 × 0.5 = 250 CR
- 友好度 100, 距离 0 → volume = 1000 × 1.0 × 1.0 = 1000 CR
- 友好度 30, 距离 1000 → volume = 1000 × 0.3 × 0.0909 = 27 → 钳到 100 CR

## 11. M28 行业情报 — 派间谍获取完整月报

**M25 "信息差"玩法的具体实现**。

### 11.1 机制

玩家向友好度 ≥ 3（盟友级，friendly ≥ 61）的 NPC 城市派间谍，获取**完整月报**（不脱敏）。

### 11.2 规则

| 规则 | 阈值 / 公式 |
|---|---|
| 最低友好度 | visible ≥ 3（盟友级） |
| 成本 | 2000 CR（叙事代价，不实际扣款） |
| 月限 | 1 次 / 城市 |
| 冷却 | 1 月 |
| 被发现概率 | friendly ≥ 70 → 10%；friendly < 70 → 30% |
| 被发现惩罚 | 友好度 -20 |

### 11.3 完整月报字段

成功时返回 IndustryEconomy.last_report 完整字典，包括：

- `sectors`（7 行业就业/营业额/利润/crisis 状态）
- `labor_force` / `unemployment_rate`
- `government_cash_cents`
- `wage_arrears_cents` / `current_unpaid_wages_cents`
- `food_production_units` / `material_production_units`
- `stockpile_food_units` / `stockpile_material_units`
- `monthly_trade_volume_cents` / `cash_months`
- `transactions`（每笔交易）
- `arrears_by_employer`（按雇主的欠薪分布）

### 11.4 REST 端点

- `POST /api/world/espionage` — 派间谍。返回 `{success, discovered, cost_cr, full_report, relation}`
- `GET /api/world/cities/:id/intelligence` — 获取完整 last_report。visible < 3 返回 403

### 11.5 前端

NPC 详情面板「行业情报」按钮仅盟友级（visible ≥ 3）显示；成功显示完整月报（劳动力/失业率/GOV 现金/累计欠薪/7 行业就业）。

### 11.6 风险权衡

- 友好度 80 派间谍 → 10% 发现 → 大概率拿到情报
- 友好度 70 派间谍 → 10% 发现（临界点友好级 70%）
- 友好度 65 派间谍 → 30% 发现（友好级临界）
- 发现失败：友好度 -20，可能从盟友级掉回友好级

## 12. M24 游戏结束 — 经济触发器与市长下台

**校长修正 2026-10-16 落地的"经济崩溃=玩家责任"机制**。

### 12.1 5 条触发规则

外置于 `data/governance_triggers.json`：

| 规则 | 阈值 | 宽限期 | 类型 |
|---|---|---|---|
| 失业率危机 | ≥ 30% | 3 月 | grace_period |
| 政府现金破产 | ≤ -1000 CR | 3 月 | grace_period |
| 累计欠薪失控 | ≥ 1000 CR | 2 月 | grace_period |
| 人口锐减 | 单月 -20% | 0 | immediate |
| 失业 + 欠薪 multi | — | 0 | multi（immediate） |

### 12.2 触发后行为

- `IndustryEconomy._trigger.is_game_over = True`
- `advance(months=N)` 在触发月立刻 `break`，不再推进后续月份
- REST `/api/industry/commands` 除 `new_game` / `save` / `load` 外一律 409
- REST `/api/world/advance` 玩家下台时返回 409，NPC AI 与世界时钟冻结
- 前端 `/industry` 顶部红色横幅 + 月进按钮置灰
- 前端 `/world` 玩家城金色光晕变灰

### 12.3 玩家选择

| 操作 | 用途 |
|---|---|
| `new_game` | 重建一个新城市（重置月份、scenario、触发器） |
| `save` | 保存当前下台状态 |
| `load` | 读取存档（保留历史月报供复盘） |

### 12.4 核心约束

**触发器只读不写**——只读 `last_report`，不修改经济数据，不影响 `assert_invariants()` 守恒校验。

### 12.5 历史意义

M24 是**校长修正三大支柱之一**：
1. 经济崩溃 = 玩家责任（M25/M27 明示）
2. NPC 后台统计 + 世界地图（M25 已完成）
3. **月初报告极度异常 → 市长下台 → 游戏结束（M24 本次完成）**

至此**校长修正完整落地**。

### 14.3 设计哲学

- **经济崩溃是游戏内容**——M24 触发器不修复"问题"，而是把"问题"变成市长下台事件
- **跨城资金流是叙事信号**——M26/M27/M28 都避免真实扣款，因为 IndustryEconomy 守恒不可破
- **玩家是经济崩溃第一责任人**——不在经济内核层面追求 120 月长期健康门
- **信息差驱动外交**——M25/M26/M28 形成"友好度→可见等级→外交→情报"完整链路
