## 1. 设计目标

**M28 = 让玩家主动消除"信息差"，获得完整月报。**

M25 的脱敏机制（M25 设计文档）让玩家看不到 NPC 城市的完整数据，但通过 5 级可见等级逐渐解锁。M28 让玩家**主动**跨过脱敏限制——派间谍获得**完整月报**（含 sectors / transactions / housing / arrears_by_employer 等所有字段）。

这是 M25 后台设计中的"信息差"玩法扩展——让"友好度自己决定能看到什么"变成"友好度只决定自然可见，但玩家可以花成本看到更多"。

## 2. 游戏体验

### 场景 1：新手玩家友好度 50（陌生人/认识/友好）

玩家打开 `/world`，点击碧涛港（友好度 50）：

```

- 友好度：50 / 100
- 可见等级：2（友好）
- 字段：人口量级、劳动力、7 行业就业 + 财政（七行业月营业额 + 政府现金）
- 锁定字段：「？？？」粮食月产/原料月产/库存/月贸易额

注意：看不到「行业情报」按钮（friendly < 61）
```

### 场景 2：玩家外交到盟友级

玩家用 M26 trade_agreement 多次签订（每次 +1 友好度）：
- 第 1 月：50 → 51（友好）
- 第 6 月：51 → 56（友好）
- 第 12 月：60 → 61（盟友）
- 第 13 月：61（盟友级）

这时再点击碧涛港：

```
城市详情面板新增：
- 友好度：71 / 100
- 可见等级：3（盟友）
- 字段解锁：粮食月产/原料月产/库存（Lv.3 解锁）
- 新增「行业情报」区域：
    "派间谍（成本 2000 CR + 风险）"蓝色按钮
```

### 场景 3：派间谍成功

玩家点「派间谍」按钮：

```
1. 客户端 fetch POST /api/world/espionage
2. 服务端校验：
   - visible=3 ≥ 友好级 ✓
   - 本月未派遣过 ✓
   - 上次派遣 ≥ 1 月前 ✓
3. 掷随机数：rng.random() < 0.10（友好度 ≥ 70，被发现概率 10%）
4. 假设骰到未发现 → success=True, discovered=False
5. 服务端调 DiplomacySystem.adjust_friendliness 无变化
6. 返回 full_report（碧涛港的 IndustryEconomy.last_report 完整字典）
```

前端渲染情报详情：

```

## 3. 5 级情报到脱业的逻辑

回顾 M25 设计文档的脱敏逻辑：

| 友好度 | 可见等级 | 自然解锁字段 |
|---|---|---|
| 0-20 | Lv.0 陌生人 | 仅城市名 + 千人量级人口 |
| 21-40 | Lv.1 认识 | + 百人量级劳动力 |
| 41-60 | Lv.2 友好 | + 7 行业就业 + 财政 |
| 61-80 | Lv.3 盟友 | + 月产（粮食/原料库存） |
| 81-100 | Lv.4 完全开放 | 全部字段 |

M28 在 Lv.3（盟友级）解锁「派间谍」按钮。Lv.4 自动看到完整月报，间谍则不再需要（除非 M28.2 增加更高级情报）。

## 4. 间谍机制与风险

### 4.1 友好度阈值

`min_visibility=3` 要求玩家至少与 NPC 是盟友级（friendly ≥ 61）。这是设计上有意为之——"陌生人不会对你间谍友好"。

### 4.2 成本与冷却

- 成本：2000 CR（叙事代价，不实际扣款）
- 月限：每城市 1 次
- 冷却：1 月（上次成功到下次允许之间隔 1 月）

### 4.3 风险等级

被发现概率按友好度分级：

- **friendly ≥ 70**：低风险（10% 被发现）—— 双方"盟友以上"，间谍很容易混进商业代表
- **friendly < 70**：高风险（30% 被发现）—— 友好级是临界点，反间谍工作更强

### 4.4 失败惩罚

被发现 → 友好度 -20。这是设计上有意为之：

- 友好度 71 + 被发现 → 51（掉回友好级，丢失行业情报权限）
- 友好度 80 + 被发现 → 60（接近友好级临界点）
- 友好度 50 + 被发现 → 30（掉到认识级）

### 5.1 模块依赖

```

backend/systems/v21/espionage.py

        └─ attempt_espionage(cfg, target, month, friendliness, rng) → EspionageAttempt

        ├─ POST /api/world/espionage

### 5.3 EspionageAttempt

```python
@dataclass
class EspionageAttempt:
    target_city_id: str
    month: int
    cost_cr: float
    success: bool
    discovered: bool = False
    friendliness_delta: int = 0
    note: str = ''
```

### 5.4 attempt_espionage 流程

```python
def attempt_espionage(cfg, target_city_id, current_month, friendliness, rng) -> EspionageAttempt:
    if friendliness >= cfg.discovery_friendliness_threshold:
        discovery_prob = cfg.discovery_probability_low  # 10%
    else:
        discovery_prob = cfg.discovery_probability_max  # 30%
    discovered = rng.random() < discovery_prob
    if discovered:
        return EspionageAttempt(..., success=False, discovered=True,
                                friendliness_delta=-20, ...)
    return EspionageAttempt(..., success=True, discovered=False,
                            friendliness_delta=0, ...)
```

## 6. 核心约束：叙事优先，不破坏守恒

**M28 与 M26/M27 一致：不实际发生资金流动。**

理由：

1. **M28 阶段引入跨城扣款会破坏守恒**：spy cost_cr=2000 直接从玩家 GOV cash 扣，但这是**对外支出**，IndustryEconomy 没有"对外情报支出"科目，会让 `cash + OCEAN == initial_total_cash` 守恒失效。
2. **M28 阶段引入被发现后的友好度惩罚已有副作用**：friendly -20 是真实影响 DiplomacySystem（不是 IndustryEconomy），所以守恒不受影响。
3. **设计意图**：M28 是**关系层扩展**（"信息差消除"），不是经济层扩展。

代价：**玩家不实际付出 2000 CR**。这与 M26 aid / M27 trade 一致——"成本"是叙事代价。

后续路线：M28.1 引入 `IndustryEconomy.spend_on_espionage(cost_cr)` 方法，绕过守恒校验（与外部资金流）；spy cost 此时升级为"有 cash delta"。

## 7. 边界与限制

- **min_visibility=3**：friendly < 61 不能派遣。
- **max_per_month=1**：每城市每月上限 1 次。
- **cooldown_months=1**：上次成功到下次允许之间隔 1 月。
- **cost_cr=2000 不实际扣款**：仅作文叙代价。
- **被发现概率 10/30 按友好度分级**：friendly ≥ 70 → 10%；friendly < 70 → 30%。
- **被发现惩罚 -20 友好度**：直接调 DiplomacySystem.adjust_friendliness（不是 IndustryEconomy）。
- **不能对自己派遣**：target_city_id == player_city_id 返回 400。
- **玩家下台后不能派遣**：返回 409。
- **intelligence 端点 visible < 3 返回 403**：不能"绕过派间谍直接看完整月报"。

## 9. 后续路线

### M28.1：真实情报支出

- 引入 `IndustryEconomy.spend_on_espionage(cost_cr)` 方法
- 玩家 GOV cash 减 2000（破坏守恒 → 走"transfer exception"路径）
- 玩家可通过其他资金路径（贸易、税收）补回

### M28.2：高级情报

- friendly ≥ 4（完全开放）无需间谍，自然看到完整月报
- friendly < 3（友好以下）即使被拒也只能看 5 级脱敏
- 这给玩家强烈动机升级到盟友级

### M29：世界事件

- 随机世界事件（瘟疫/丰收/战争）按距离影响周边城市友好度+经济指标
- 事件来自 WorldGame.world.month 推进时触发

### M30：长期政治

- NPC 城市联盟/敌对关系，玩家可加入任一阵营
- 影响全局贸易格局与外交决策
