## 13. K 与宜居度（V2.1 §10.6 + §14.13）

**V2.1 §10.6 K 定义**：
```
K = floor(s^0.25 * min(K_H, K_F, K_J))
```

**首月值**（V2.1 §14.13）：
- H = 3,600（住房人口容量）
- K_F = 3,300（月可持续粮食供给）
- J_op = 1,800（可支付岗位上限）
- e = 1,500 / 1,650 ≈ 0.9091
- s = 0.95（安全系数）
- K_J = J_op / (lambda × e_target) = 1,800 / (0.55 × 0.90) ≈ 3,636.36
- K = floor(0.95^0.25 × 3,300) ≈ 3,257
- K/N ≈ 1.0857

**V2.1 §11.1 L 定义**：
```
L = 100 × (0.35h + 0.35a + 0.20v + 0.10s)
h = clip((K/max(N,1) - 0.90) / 0.45, 0, 1)        [容量余裕]
a = clip((total_disposable_income/max(N,1)) / (1.20 × Cneed_city), 0, 1)  [实际购买力]
v = clip(A_service/max(N,1), 0, 1) × clip(funded_public_ops / required_public_ops, 0, 1)
s = security_coefficient
```

**首月值**（V2.1 §14.13）：
- h ≈ 0.413
- 居民税后人均收入 154,557 / 3,000 ≈ 51.519
- Cneed = 50（世界标准）
- a ≈ 0.85865
- v = 0.65
- s = 0.95
- **L ≈ 67** 分

**与 V1.0 关键差异**：
- V2.1 给出 K 与 L 的**精确公式**（V1.0 仅给原则），是 P0-C-06 迁徙吸引力指标（A-06 V2.1 §11.1）改造的基础。
- L 公式分母 0.45 经开局城市校准选定，使 K/N≈1.08~1.30 的城市在其他条件正常时具有不同但可比较的 L。**V2.1 明确修订**：旧讨论稿的 0.30 会把港城和学城开局 L 推到约 89 分、超出本书 65..82 的普通开局预设目标。
- 双重计量预防：食品短缺/就业短缺先压低 K，不额外把同一短缺作为多个惩罚项；安全在 K 及 L 中均出现，**L 直接安全权重仅 0.10，避免过强**。
