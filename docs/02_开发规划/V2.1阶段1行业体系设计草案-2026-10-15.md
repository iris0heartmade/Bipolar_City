## 0. 阶段 1 目标

把 V1.0 的 6 行业重构为 V2.1 的 7 行业（AGR/IND/SRV/CHU/BNK/MAG/GOV），含 BNK 银行与 MAG 魔法学院两个全新行业，行业税级 A=15/B=12/C=8/无=0 分级，工资级 A=100/B=90/C=75/D=60 重构。

from dataclasses import dataclass
from enum import Enum
from typing import Optional


class WageTier(str, Enum):
    """工资级 A/B/C/D，对应 100/90/75/60 CR/在职人/月（V2.1 §2.2）"""
    A = 'A'  # 100
    B = 'B'  # 90
    C = 'C'  # 75
    D = 'D'  # 60


class TaxTier(str, Enum):
    """行业税级 A/B/C/无，对应 15/12/8/0% 正利润税率（V2.1 §2.3）"""
    A = 'A'        # 15%
    B = 'B'        # 12%
    C = 'C'        # 8%
    NONE = 'none'  # 0%（亏损或免税行业）


WAGE_TIER_CR = {WageTier.A: 100, WageTier.B: 90, WageTier.C: 75, WageTier.D: 60}
TAX_TIER_RATE = {TaxTier.A: 0.15, TaxTier.B: 0.12, TaxTier.C: 0.08, TaxTier.NONE: 0.0}


# 行业 ID 枚举（V2.1 §2.1 七行业）
class IndustryId(str, Enum):
    AGR = 'AGR'   # 农业
    IND = 'IND'   # 工业
    SRV = 'SRV'   # 服务业/商业
    CHU = 'CHU'   # 教会
    BNK = 'BNK'   # 银行（V1.0 缺失）
    MAG = 'MAG'   # 魔法学院（V1.0 缺失）
    GOV = 'GOV'   # 公务员

    """行业静态定义（V2.1 §2.1）。"""

    job_capacity_max: int            # 基础阶段理论岗位上限
    wage_tier: WageTier
    tax_tier: TaxTier
    initial_employees: int           # 工业新城首月初始就业

INDUSTRY_DEFINITIONS: dict[IndustryId, IndustryDefinition] = {

## 6. 行业状态类（V2.1 §1.3 SectorState）

```python
@dataclass
class SectorState:
    """V2.1 §1.3 行业运行时状态（每城每行业一份）。"""
    industry_id: IndustryId
    definition: IndustryDefinition        # 静态定义引用
    account: str                         # 经营现金账户 ID（如 'firms:IND'）
    job_capacity_J: int = 0              # 当前建筑配置岗位上限
    sustainable_job_capacity_Jop: int = 0  # 可持续支付岗位
    employees_E: int = 0
    wage_per_worker_w_cents: int = 0     # 整数分
    operating_cash_M_cents: int = 0      # 经营现金
    base_capacity_per_good_g: dict[str, int] = field(default_factory=dict)
    planned_output_g: dict[str, int] = field(default_factory=dict)
    produced_output_g: dict[str, int] = field(default_factory=dict)
    paid_input_g: dict[str, int] = field(default_factory=dict)
    cash_revenue_R_cents: int = 0
    cash_operating_cost_cents: int = 0
    depreciation_cents: int = 0
    pre_tax_profit_cents: int = 0
    industry_tax_cents: int = 0
    after_tax_profit_cents: int = 0
    dividend_cents: int = 0
    debt_cents: int = 0
    production_efficiency: float = 0.0
    special_points_output_g: dict[str, int] = field(default_factory=dict)
    # V2.1 阶段 5 跨城交易加：export_orders, import_orders, transit_stock
    # V2.1 阶段 4 银行加：loan_principal_outstanding_cents
```

## 7. 阶段 1 实施工作清单

按依赖顺序：

1. **创建 `backend/systems/v21/industries.py`** — IndustryId 枚举 + WageTier/TaxTier + IndustryDefinition + INDUSTRY_DEFINITIONS
2. **创建 `data/economy_v2/industries.json`** — 七行业配置
3. **创建 `backend/systems/v21/loader.py`** — JSON 加载器（兼容 UTF-8 BOM）
4. **新增 `tests/v21/test_industries.py`** — 测试 INDUSTRY_DEFINITIONS 全部字段、V2.1 §2.1 数字匹配、JSON 加载
5. **不写 SectorState 运行时代码**（V2.1 阶段 2 居民群体完成后才能定义完整 SectorState）
6. **不写工资发放逻辑**（V2.1 阶段 6 通胀与工资）
7. **不写经营生产逻辑**（V2.1 阶段 9 月结算引擎）

**预计代码量**：3 个新文件 + 1 个测试文件，共 200-300 行 Python + 50 行 JSON。

## 8. 与 V1.0 差异

| 项 | V1.0 实现 | V2.1 设计 |
|---|---|---|
| 行业数 | 6 | **7**（+BNK +MAG） |
| 工资级 | 散定（65-110） | **A=100/B=90/C=75/D=60** |
| 税级 | 统一 12% | **A=15/B=12/C=8/无=0** |
| 行业现金 | 合并在 `firms` | **七行业独立钱包** |
| GOV 税 | 12% | **0%**（对自身征税无意义） |
| 数据类 | `SectorAggregate`（合并 6 行业） | `IndustryDefinition`（7 行业静态）+ `SectorState`（7 份运行时） |
| 配置文件 | `input_output_v1.json`（V1.0 投入产出流量） | `industries.json`（V2.1 行业定义）+ 未来 `sectors_v2.json`（运行时状态） |
