# 行业双指标建模与验证计划

日期：2026-10-15。范围：建立行业容纳限度、行业吸引力及劳动力进入/退出模型；交付规范、外部参数、独立数值参考和验证记录，不接入当前未完成的游戏月结。

## 结构

```text
行业双指标模型
├─ 输入：现有行业工资/税制/岗位/现金/投入产出 + 可审计历史
├─ 容纳限度：建筑、当月支付、持续经营、必要投入
├─ 吸引力：收入、稳定性、工作环境
├─ 用工目标：真实订单或有资金的公共服务计划
├─ 劳动力流动：被动退出 → 待业者招聘 → 在职转行
└─ 输出：人数、分项原因、流动矩阵、约束检查
```
