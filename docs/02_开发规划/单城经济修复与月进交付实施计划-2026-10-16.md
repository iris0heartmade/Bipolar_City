# 单城经济修复与月进交付实施计划

> 执行方式：使用 subagent-driven-development 按边界实施；主代理完成规范核对、代码审阅和整体实测。用户已批准2026-10-16评估报告的修复与单城交付方向，本计划直接执行。

**目标：** 修复评估确认的全部当前运行问题，交付可持续月进、可施策、可恢复存档、具备真实建设代价的单城版本，并以24/120个月实验核对经营与恢复能力。

**架构：** 保留 IndustryEconomy 为唯一正式经济内核；地图和桌面各自持有城市实例，通过副本校验后提交。配置、运行状态、命令记录分离；禁止通过报表修数或隐藏注资校准结果。

**技术：** Python、FastAPI、Tk、JavaScript/Canvas、pytest；浏览器与桌面事件循环用于最终操作验收。

## 1. 边界与规则

```text
单城交付
├─ 经济任务：industry_economy / industry_model / industry_settle / demography / industry_scenario
├─ 地图任务：game_api / 地图前端 / 建筑经营配置
├─ 桌面任务：economy_lab / 独立实验会话 / GUI检查
└─ 主代理：industry_api / 长期实验 / 校准器 / 交叉回归 / 文档
```

各任务共享工作区，按文件分工，禁止覆盖其他任务改动。经济按月在一个城市实例内串行运行；桌面仅一个后台工作线程，提交带修订号的结果，关闭时停止提交新任务。

人口采用一致的总居民数、劳动力和就业三层口径；家庭倍率明确为消费等价系数，不声称人口或统计数据。自然变化采用年率换月率，保留小数余量；移除无法兑现的实证回归声明。政策在下一个结算月开始，N月恰好覆盖N次结算。欠薪记录到雇主/群体债权并可实际偿付；存档版本升级，旧不完整状态显式拒绝，不静默补全经济历史。

新建建筑由政府实际付款给施工行业，下一月完工后增加岗位/住房及相应行业产能；未完工不提供能力；拆除不能超卖能力或驱逐无替代住房的住户；迁址保留能力并核对完整占地、道路入口。容量、费用和维护来自配置。现有初始城3600住房容量作为既有全城住房底座，初始可视住宅不重复加成。

远期金融深化、完整多城世界、人物和议会是本次确认的后续路线，不在本次伪装成已实现；本轮完成其前置的可信单城与实测门槛。
