# 经济实验室反馈模型

日期：2026-10-14；依据：经济输入 V1.0、2026-10-14 审查报告、用户要求。

## 目录
1. 模型边界
2. 月度顺序与账户
3. 正负反馈
4. 场景与验收

## 1. 模型边界
保留六行业与三收入群体聚合模型，完善实验室计算路径。逐店、道路最短路与游戏地图接入保持独立阶段。采用可复现的月度条件冲击，不用预设破产结果或直接覆盖报表。新增数值均为公开的游戏校准假设。

## 2. 月度顺序与账户
月初生效冲击与已完工状态 → 岗位匹配 → 以历史收入和期初钱包冻结预算 → 优先支付公共工资 → 采购并限制资源 → 实际成交 → 私企工资/房租/利润税/分红 → 个人税/救济/教会 → 债务付款 → 冻结本月收入、成交与价格统计 → 更新下月工资/价格/投资/退出/人口/教育 → 生成月报并断言。公共工资提前付款是避免采购侵占工资的实施约定；本月消费预算已冻结，不以新工资即时扩大预算。

每行业、每居民群体各有真实钱包；房东为居民财产子账户，不增加人口。复用现有 Settlement。消费未成交保留现金；欠薪和必要费用欠付保留累计义务，交易收入只取实际到账。资本购买是资产而非本月成本，折旧不重复扣现金。战略贸易从总贸易拆出，只结算一次；物资仅按实付进口数量、实际产销更新。

聚合行业间矩阵采用采购成本权重作为买方权重、基准销售权重作为卖方权重，这是输入未指定交易矩阵时的显式假设。市场以固定预算竞争，价格不能制造购买力。

## 3. 正负反馈
- 正反馈：真实订单增加 → 利润/现金改善 → 有资金的设备投资、扩张和新企业 → 招聘 → 收入/迁入/需求增加。所有扩张均有付款和资产记录。
- 负反馈：订单下降或进口涨价/断供 → 利润压缩、资金不足 → 减少投资、裁员 → 购买力下降 → 连续亏损/欠薪后的破产；有资金但连续经营不利的企业可搬走并带走现金。
- 工资以固定基准工资为锚，受相对岗位紧张度、物价和信仰影响；遵守调整上限与最低工资。招聘、裁员、迁徙维护就业+失业+非劳动力=人口，户数随人口变动。
- 教育有培训延迟，投入不足降低完成率；政府或教会救济受钱包限制。教会先救济，再按剩余储备捐市政；失业增加且捐款减少时可出现救济缺口与储备耗尽。
- 对外订单、迁入储蓄、资本外逃和债务本金分开记账；财政余额来自实际经营收付，本金不算费用。
- 价格和租金缓慢调整；贫困按实际可支配收入与明确生活线计算；需求恶化不要求短期立即恢复。

## 4. 场景与验收
场景配置包含冲击开始/结束月份，支持先繁荣再衰退及恢复。现实资料用于因果链，冲击幅度是游戏压力条件，不声称拟合真实国家。

必测：基准120月、外需繁荣、需求衰退、进口涨价、煤炭供应中断、公共债务危机、低储备教会救济、复合灾难、冲击解除后的恢复、极端税率/最低工资/零现金/零就业。

硬约束：整数分、现金守恒、非负本地钱包与库存、人口身份、岗位约束、报表与交易核对、负利润可见、进口实付对应数量、欠付不造收入。行为验收：良好条件可增长，坏条件可破产/外逃/失业/救济不足，短暂冲击与长期冲击有不同结果；不把“一律存活”作为成功条件。

## 实施约定补充

- 家庭期初现金为两个月可支配收入，企业期初资金沿用逐行业两个月固定支出校准；不再把企业现金绑定到市政期初现金。
- 正常基准可能出现温和价格下降，增长用基准价实际产量判断；不能把价格变化当成产量变化。
- 自然增长受住房容量约束；自然减少维护群体身份，迁徙仍受每月上限限制。
- 战略物资采购设置进口数量上限，煤炭等无基准进口渠道的物资不会自动无限进口；每笔战略进口附带物资与实付数量。
- 无资金时可选择未成交、少采购、欠付义务或企业退出，不隐式借款。企业自有资金开业从累计真实设备采购中满足门槛；全行业退出后的外部创业融资仍属后续信贷模型。

- 三群体消费篮子用配置中的有限轮校准矩阵保留偏好并复现首月行业总额，后续群体预算、价格与可供货量共同改变订单；不存在凭空放大消费总额。
- 教会救济压力相对于正常参考城失业率并随人口缩放；初始就高失业的城市不因缺少上个月的失业增量而免除救济需求。
