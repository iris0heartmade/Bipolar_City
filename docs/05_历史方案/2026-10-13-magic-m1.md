# 魔导城市视觉与 M1 实施计划

**目标：** 改造魔法工业 UI，并落实住房出售、公房租赁与集市商户的首个经营闭环。

**架构：** 沿用单一 Python 权威模拟。增加住房与商户系统、配置化经济参数、版本 1 迁移入口；前端增加产权工具和经营面板。无需多进程或第二条经济循环。

**技术：** FastAPI、Python dataclasses、原生 JavaScript、CSS、Canvas/SVG、pytest 与 Playwright。

用户已要求按原方案继续开发，本轮在当前会话顺序执行，不派发子代理。
