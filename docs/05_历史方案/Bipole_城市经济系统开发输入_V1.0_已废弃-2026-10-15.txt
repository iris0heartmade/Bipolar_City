城市经济系统开发输入书 V1.0
City Economy Simulation Design & Calibration Baseline
编制日期：2026-10-13
文件格式：UTF-8 纯文本（TXT）
用途：供游戏开发、经济模拟、数值策划与自动化测试直接使用

======================================================================
0. 项目边界与设计原则
======================================================================

0.1 已确定的游戏约束
- 时代：Bipole 世界观下的工业革命时期；工业、贵族、宗教与魔法师并存。
- 画面：斜45度等距视角、完全格子化城市；默认地图 64 x 64。
- 技术：Web 前端（JS/Canvas 等）+ JavaScript/Python 经济模拟后端优先；不采用 Godot。
- 玩家：市政管理者。主要通过规划、公共建筑、财政、税率、政策影响城市。
- 住房：以私人产权和NPC开发为主，政府规划用地；不得默认所有住宅都由玩家直接投资。
- 企业：民间商户/工厂NPC自主入驻、招聘、经营、扩张、退出；允许少数公营企业。
- 贸易：普通商品按产业价值/订单抽象；粮食、煤炭、钢铁、魔法材料等战略品具有实体库存。
- 城际：自由市场 + 特定战略物资贸易协议；初版允许5~8个简化NPC城市。
- 国家：保留中央政策与财政转移支付接口；议会、热冲突、深度外交暂缓。
- 宗教：轻量社会因素。仅四种常规经济效应 + 五档传教政策，不做可操作的教会经营游戏。
- MVP优先顺序：住宅用地→私人施工→人口迁入→就业/消费→商业→财政/贷款→存档；
  多人实时同步、复杂政治、三科技树、复杂公共交通、金融危机、战争后置。

0.2 一个核心原则：资金守恒，不是“所有指标相互加成”
- 工资必须由雇主（企业/政府）支付；企业收入必须由顾客/贸易订单实际支付。
- 商户营业额不是利润；工资与分红流入居民，但不是整个城市新创造的货币。
- 公共建设必须花钱，贷款必须记债务，房租必须有收款人。
- 道路、学校、魔法师与宗教不直接凭空创造营业额；它们通过成本、可达性、技能、风险、工资和人口改变经济结果。
- 全市“营业额之和”含中间交易，不等于城市经济增加值（GVA/GDP）。
- 对外净流入（出口/外来游客/中央拨款/外来投资 - 进口/利息等）才能改变城市整体净持币余额。
- 数字全为架空世界首版平衡值；“偏真实”指结构、量级比例与因果合理，不冒充历史原始统计。

0.3 时间、货币、空间和类型
SIM_TICK = 1 month; MONTH_DAYS = 30; YEAR_MONTHS = 12。
CURRENCY = CR（克朗，架空记账单位）；最小记账单位=0.01 CR。
存储货币：强制使用整数分（1 CR=100分）或Decimal，禁止二进制浮点累计现金。
地图：64x64 tile；测试时每格按20m地面边长计算；完整地图约1.28km x 1.28km。
世界坐标与道路最短路以格为单位；20m只是第一版换算基准，不影响世界观。
人数单位=人；住房单位=套/户；企业数=家；战略资源=吨或箱；路程=分钟。
价格指数：初始 CPI=1.000；基础商品抽象单位价格 P_ref=1.000 CR/单位。
区分 stock（期末存量）与 flow（每月流量）。

1. 系统结构与推荐状态变量
======================================================================

1.1 状态实体（MVP必须）
A. CityState：cash, debt, inflation_index, population, stability,
   policies, revenues, expenses, current_month, map_id。
B. District/Block：grid_cells, housing_units, residents_by_group,
   employment_access, road_access, risk, land_value。
C. HouseholdCohort：population, households, workers_by_skill,
   income, cash_savings, tax_paid, expense_baskets, faith_share。
D. PrivateFirm：industry, tile, capacity_units, headcount_by_skill,
   wage_offer, cash, goods_stock_if_strategic, target_price,
   sales, input_cost, rents_paid, profit, tax, expected_profit。
E. PublicFacility：facility_type, tile, capacity, staff, staff_wages,
   monthly_purchase_cost, upkeep, risk_or_service_coverage。
F. PropertyOwnerAggregate：residential_rents, commercial_rents,
   property_maintenance_cost, property_tax, owners_in_household_cohorts。
G. TradeMarket：product_prices, imports, exports, orders, transport_cost,
   counterpart_city_id; 初版简化成交市价，不用真实每人拍卖。
H. ChurchAggregate：faith_ratio, offering_received, municipal_grant,
   reserve_cash, missionary_policy；只有一个聚合账户，无独立NPC经营。
I. LoanAccount：principal, monthly_rate, grace_months, maturity_month,
   lender_is_external, payment_schedule。

1.2 人群结构（避免逐人模拟）
- 人口按住宅块 + 收入层次 + 技能/职业 + 信徒比例聚合。
- 职业和财产身份分离：魔法师可有商铺，地主可雇工，不额外创造人口。
- 记录 employed / unemployed / out_of_labor_force，三者合计全城人口。
- 基础职业技能：basic（基础劳动）、skilled（技术）、professional（高技能）、mage（魔法）。
- 初版不用复杂年龄队列；使用“儿童等非劳动力人口”聚合。

1.3 输出口径（三类不能混淆）
- 商户收入：营业额 R；利润 Pi_pre / Pi_after；现金余额 delta_cash。
- 居民平均收入：总税前收入/人口、可支配收入/人口；还应显示劳动者平均工资。
- 财政收入：税、行政收费、公营净上缴、中央转移支付、教会捐赠；贷款不是财政收入。
- 城市经济增加值 GVA：各产业最终增加值合计；禁止将本地企业间购销重复计入。

4. 核心生产、市场、利润和工资模型（MVP计算式）
======================================================================

4.1 生产能力
对企业i、月份t：
Qcap_i = K_i * F_labor_i * F_skill_i * F_resource_i * F_service_i * F_safety_i * F_worktime_i
其中K_i是价格基准P_ref时的产品/服务单位数；F因子建议区间0~1，
训练/技术可单独通过K_i升级，不在每个模型中叠乘任意“等级+X%”。
F_labor = min(1, (L_actual / max(1,L_required)) ^ 0.80)。
F_skill = clamp((effective_skill / required_skill)^0.30, 0.65, 1.00)。
F_resource = min(1, 本月可用关键资源/本月计划消耗)；无相关资源限制则=1。
F_service = 关键能源/供水的运行系数，MVP可默认为1。
F_safety = 1 - expected_attacks * downtime_fraction，限制[0.65,1]。
F_worktime = (1-0.04*f_t)/(1-0.04*f_ref)，f_ref=0.55；
  相对于初始城市校准，不将初始宗教时间损失重复扣掉。
产品售价P_i可变，但产能以“实物/抽象服务单位”计，不直接用当期金额计产能。
已知同业初始参考单价P_ref=1，可先以“基准价值单位”作为Q单位。

4.2 用历史营业额反推初始基准产能（80%产能利用率示例）
行业                 初始销量单位/成交额    初始理论月产能K_i
农业                          47000                58750
轻工业                       120000               150000
重工业/矿业                   78000                97500
零售商贸                      50000                62500
交通物流                      27000                33750
生活服务                      18000                22500
合计                         340000               425000
初始P_ref=1；0.80产能利用率为便于扩张的校准选择，不代表每家都必须80%。
如果把安全损失、技能失配、宗教劳动时间纳入实际状态，反推K_i时要按基准状态
重新归一化，禁止在本表80%上又重复扣同一个基准风险损失。

4.3 市场需求：预算先产生，企业再争夺
家庭cohort h在月初得到消费预算：
B_h,t = clamp(0, disposable_income_h,t-1 + cash_draw_h,t - planned_saving_h,t,
              disposable_income_h,t-1 + cash_savings_h,t-1 + available_credit_h,t)。
先扣预计房租、基本捐助等约束，再将剩余预算分配给食品/燃料/服装/服务等行业。
历史收入只决定预算，不保证真正成交；预算未花完自动转回储蓄。
需求来源还包括企业中间采购、资本投资、市政采购、游客和出口订单。
消费预算不足时依序保障食品基本量、基本燃料、住房租金；贫困与欠租产生负反馈。

4.4 居民选择商户：利用真实道路网络
住宅区z到商户i道路最短时间t_zi；没有联通路径则不可达/仅可高成本绕行。
V_zi = 0.40*quality_score_i - 1.10*(p_i/p_ref_cat) - 0.07*t_zi(minutes)
weight_zi = exp(V_zi - max_V)；数值计算使用减max_V以防溢出。
spend_zi = B_z,category * weight_zi / (sum(weight_zj) + weight_outside)。
weight_outside代表外地消费/未满足的替代选择，并非凭空消失的货币。
如果某商户销售能力不足，用最多3轮预算重分配给可供货商户；
仍未满足的需求形成缺货/外购/未消费，保留消费者钱或支付给外部市场。
商户实销量 = min(供给Qcap+可用成品库存, 获得的已支付需求订单)。
营业额R_i = 实销量 * 实成交价；按付款方逐笔生成Transfer记录。

4.5 道路与物流
步行速度：1.1 m/s；每格20m，步行每格约0.303分钟；
马车基础速度：3.0 m/s；每格约0.111分钟。
道路类型修正（只改变速度与容量）：地方泥土路0.75；铺装道路1.00；城市干道1.30。
拥堵时间因子=1+0.15*(flow/capacity)^4；初版可只用容量分档近似，避免逐车模拟。
物流成本_i = sum(shipment_volume_r * route_unit_cost_r * congestion_factor)
                   + 外部货运关税/服务费（如存在）。
强制分清：道路提升客源、通勤和货运，不直接为商店乘以“道路加成”。
若建新路只是使消费者从A店转到B店，全市消费未必增加；只有减少跨城购物、
提高真实生产/出口、降低浪费，城市总经济才有净增长。

4.6 企业工资与招聘（工资变化逐步发生）
企业按技能岗位招聘，先匹配通勤可达人员，再看工资报价。
设skill s的岗位紧张度theta_s = demand_s/max(supply_s,1)。
基准工资表对应faith_ref=0.55，CPI_ref=1；新的长期目标报价：
Wtarget_s = Wbase_s * (CPI_t/CPI_ref)^0.70
            * (theta_s/theta_ref_s)^0.12
            * (1-alpha_s*f_t)/(1-alpha_s*0.55)。
信徒对工资容忍作用：基础劳动alpha_basic=0.10；技术alpha_skilled=0.03；
专业人才alpha_professional=0.01；魔法师alpha_mage=0.00。
工资每月向Wtarget收敛25%，单月变动最大±3%，且不低于法定最低工资。
基准工资表已包含55%信徒时的影响；不要再额外给表内工资扣5.5%。
低工资也会导致居民购买力下降，并通过消费模型影响商户收入；
禁止叠加第二个“低工资直接导致商业收入-XX%”的重复惩罚。

4.7 企业利润、税与退出
input_cost=本地/外地商品采购+物流/能源/其他服务费；商业物业租金独立记录。
Pi_pre=R-wage_paid-input_cost-rent-depreciation-license_fee。
corporate_tax=max(0,Pi_pre)*tax_rate_business（初始12%）。
Pi_after=Pi_pre-corporate_tax。
Dividend=max(0,Pi_after)*payout_rate，默认约42.9%，但现金不足时必须截断。
retained_profit=Pi_after-Dividend。
firm_cash_delta=R-cash_input-wages-rents-license_tax-profit_tax-dividend-capex
                + new_loan_principal - loan_principal_repayment - loan_interest。
折旧不计现金支出；请勿把折旧既作费用又在firm_cash_delta中扣一次。
新开业条件：规划允许+交通可达+预期月利润率>6%+初期融资覆盖1.5个月固定支出。
扩张条件：预期有订单+现金足够+用工可得+前3月平均产能利用率>85%。
退出条件：经营现金持续不足且贷款不可得；不在一个偶然亏损月立即清盘。
初版建议：连续3个月无法支付必要现金费用或连续6月税前亏损才退出。

5. 住房、人口迁移、教育和魔法安全
======================================================================

5.1 住房
开发商在住宅用地上判断：预计年净租金回报、空置率、造价、融资成本、道路可达。
仅在土地已规划、道路接入、施工资金存在时自动建造；政府可制定住房税/补贴政策。
住房容量限制迁入：new_households <= vacant_units + completed_units。
住宅租金可通过租户需求与空置率缓慢调整：
rent_next = rent_now * (1 + clamp(0.20*(occupancy_rate-0.93), -0.03, +0.03))。
目标健康空置率约5%~8%；人口多不自动创造住宅。
初始600出租户 x 47 CR/月 = 28200；业主150户自住；其他房屋50套待租/售。
土地/住宅售价上涨改变资产估值，不自动增加财政现金；仅房产税及真实交易发生现金流。

5.2 居民迁徙
每个住宅区的吸引力U_z：
U_z = 0.30*real_disposable_income_index - 0.25*housing_burden_index
    - 0.15*commute_index + 0.15*public_service_index
    - 0.15*danger_index；所有指数先统一归一化到近似0~1。
候选迁入数取决于本城/其他城市相对吸引力、可用房和就业岗位。
单月净迁徙不超过当前人口的1%（重大剧情事件除外）。
迁入/迁出带着人口、劳动力结构和信仰结构，不是直接修改信徒比例而不改人口。
MVP可将迁徙按每套房4人、工作岗位和目标家庭收入简化处理。

5.3 教育（慢变量）
教育容量=教师人数*24座/教师，初始30人->720座，学龄人口约900。
教育覆盖率=min(1,可达座位/适龄人口)；还要考虑通勤范围与教员缺岗。
当期学校只消耗资金、创造教师工资与少量客流；提升技能需经历培训/毕业延迟。
MVP：每12个月，新增skilled = floor(培训年龄人口 * 完成率 * 技能转化率)。
推荐初始完成率0.75；技能转化率0.35；培训能力受现有席位容量限制。
人才增加后必须有对应产业岗位，否则迁出概率升高；不直接给全市GDP增加固定百分比。
高阶研究、魔法学校与深度人才树后置。

5.4 魔物威胁与魔法师
H_z=该区域每月魔物事件强度；D_z=该区域魔法师/防御设施有效覆盖。
expected_attacks_z=H_z/(1+kappa*D_z)，推荐kappa=1.0。
F_safety_z=clamp(1-expected_attacks_z*avg_downtime_share,0.65,1.0)。
魔法师有效覆盖=魔法师战力*道路可达折减*是否有人值守。
初始平均风险可使外围工业区每月出现约1%~3%的潜在停工损失，
城区核心区更低；重要危险事件可由剧情额外触发。
公共20名魔法师月工资4400，加材料支出1100，已在财政支出中列入。
防御优先改变停工、货运损失、居民迁出与灾后维护费，不直接给商户固定+X%收入。

6. 轻量宗教经济模型（已定稿，不扩张为教会经营）
======================================================================

6.1 唯一核心慢变量：faith_share f in [0,1]，城市初始f=0.55。
只设4种常规效果：
【好1】教会捐市政：monthly_grant=min(church_cash_available,1200*f)。
【好2】低工资容忍：见4.6工资目标，初始基础工alpha=0.10。
【坏1】宗教免税：property_tax=assessed_value * 0.0012*(1-0.15*f)。
【坏2】宗教义务时间：worktime_factor=(1-0.04*f)/(1-0.04*0.55)。
其他宗教关系（政治立场、研究冲突、节日等）只做事件，不常驻经济乘数。

6.2 传教政策由市政面板设置，每6个月才能改一次
policy = -2 严格限制；-1 有限限制；0 宗教中立；+1 鼓励传教；+2 官方扶持。
按月信仰变化：
faith_next = clamp(f + a_policy*(1-f) - b_policy*f + migration_effect, 0,1)。
政策                  a(传入/月)     b(退出/月)    公共补贴/月
严格限制(-2)            0.0010       0.0060          0
有限限制(-1)            0.0020       0.0045          0
宗教中立(0)             0.0030       0.0030          0
鼓励传教(+1)            0.0060       0.0025          0
官方扶持(+2)            0.0090       0.0020        200
【如启用+2扶持财政支出200，应计入实际月度支出，基准账本policy=0不含这200。】
迁徙带来的faith变动要按迁入/迁出人数加权重算，不应该用一个额外百分数覆盖人口数据。
信徒不会因为市政限制传教而立刻消失；限制的是传播而非个人信仰身份。
若在高信仰城市突然改为严格限制，给稳定度一个短暂负面冲击，持续3个月衰减，
不应每月永久叠加惩罚。示例初始冲击：delta_stability=-6*f*max(0,old_policy-new_policy)。
同一连续政策实施期间不重复产生该冲击。

6.3 教会现金账户最简计算
church_cash_next=church_cash + offerings_from_households - municipal_grant。
居民捐助初始1500/月；未来按有消费能力的信徒收入与捐助倾向调整，
但必须从居民预算真实扣除；若教会储备不足，municipal_grant按可支付金额截断。
教会财务只用来防止无中生有；不能直接运营教会企业、医院、慈善院、学校。

7. 税制、政府支出与贷款（账户结算规则）
======================================================================

7.1 城市税率起点与允许调节范围
个人所得税：初始8%，允许0%~20%，每次调整最多±2个百分点，6个月冷却期。
企业正利润税：初始12%，允许0%~25%，每次最多±3个百分点。
土地房产税：初始每月0.12%，允许0.03%~0.25%，由评估价值计算。
许可证规费：初始全城1200/月，可按行业/企业固定费合计；不再加百分比。
税收征管效率：初始=1.0，MVP固定；之后可按行政能力/腐败调整0.80~1.00。
企业利润税基=税前利润>0的部分（亏损不征负所得税）。
个人所得税基=工资+收到的股息+净房产收益，抵扣/税阶以后再加。
房产税由资产所有者缴纳；政府不可将房产税同时从店家利润和所有者收入扣两次。
中央拨款初始2500/月，MVP作为固定外部转移。
市政府不能通过无限涨税直接增加财政收入；实际税基会受就业、价格和利润反馈。

7.2 支出与账户：
公共工资= sum(active_public_staff * salary)。
公共采购= sum(facility_operating_purchases)+道路等市政维护。
社会转移=按贫困/失业人数和政策计算，基准3200/月。
资本支出=实际支付到完成施工的本地/外地企业款项。
贷款利息=每笔债务principal * monthly_interest_rate。
债务本金偿还是融资现金流，不作为财政费用；利息才是费用。

7.3 预算
fiscal_income=income_tax+profit_tax+property_tax+license_fees
            +public_enterprise_net_transfer+central_transfer+church_grant。
fiscal_expense=public_wages+public_purchases+welfare+interest+public_capex
             +any_other_spending。
fiscal_balance=fiscal_income-fiscal_expense。
city_cash_next=city_cash+fiscal_balance+new_borrowing-principal_repayment。
loan_principal_next=loan_principal+new_borrowing-principal_repayment。
初始政府现金100000，本金60000，月息1.0%，宽限期内本金偿还0。
新建公共设施前检查贷款上限、现金和持续性年度维护压力。
建议新借款上限=过去12个月平均月税收*6（没有12个月历史时用当前税收估算）。

9. NPC经营：开业、扩张、倒闭和投资（允许简化）
======================================================================

9.1 NPC企业每月决策：
- 检查规划准入、门前道路、目标客户与客流、技能工人供给、固定支出。
- 预期营业额用过去3个月平滑销量和当月客群需求估计，不允许预知未来。
- 利润预期=预期营业额-预期采购-工资-租金-物流-折旧-规费-税。
- 空缺商业地块以可获得经营利润最高的合格行业优先入驻，并留随机扰动。
- 玩家不能像摆公营建筑一样免费摆放一间自动赚钱的私人店。

9.2 启用NPC投资（推荐）
平均利润率>6%，流动资金≥1.5个月固定支出，预计6~24个月回本方可建店。
高需求行业会吸引商户，新商户入驻会改变周边店铺市场份额。
城市人口减少后产生空置商铺、价格竞争与债务压力。
贷款融资必须可用且利息进入企业费用；初版可禁止NPC企业借款，仅使用初始资金，
等基本经济闭环可靠后再引入NPC私人信贷。

======================================================================
10. 结算顺序：严禁循环引用造成收入凭空增长
======================================================================

月初状态S_t（现金/人口/企业/设施/库存/价格/道路/宗教）已确定：
01. 复制上月结算结果，处理完工建设、居民迁入迁出、已生效政策与外部市场报价。
02. 计算道路可达性、供水/能源状态、魔物风险覆盖，构建空间邻近查询缓存。
03. 根据企业计划产能生成岗位需求，匹配劳动力、确定本月聘用人数和合同工资。
04. 根据上月家庭可支配收入与储蓄，设定本月消费上限，先预留房租/必要支出。
05. 根据企业采购订单与战略库存、物流网络，确定各企业可用关键投入。
06. 计算产能Qcap，公共部门服务容量以及商户供给量。
07. 分配消费、企业中间品、资本品、公共采购、旅游、贸易订单。
08. 执行真实交易：逐笔付款、扣库存、登记卖方R/买方成本；供不应求重分配预算。
09. 支付企业工资、房产租金、经营许可费；核算利润、应税额并缴企业税。
10. 分配企业股息，房地产所有者收租并支付物业维护支出。
11. 公共工资、个人所得税、房产税、政府救济、教会捐赠、市政采购与建设支付入账。
12. 支付贷款利息/本金；更新公共财政、企业现金、住户现金、教会余额。
13. 结转居民本月收入与预期，更新价格/工资目标、投资计划、破产与建房排队。
14. 更新宗教人口比例、人才培养进度、人口自然变动和本月稳定度冲击。
15. 记录统计、生成会计断言与完整存档，再进入下一个月。

重要实现说明：
- 第07步“分配订单”可以先预留交易资金和库存，但第08~12步才真实清算资金。
- 第11步公共采购和建设若在第08步已对企业付款，不可第11步重复付款；
  建议使用单一Transactions队列：各子系统只生成付款义务，统一清算一次。
- 工资、税和股息对下一期家庭消费产生影响，避免本期同一个营业额被无限循环放大。
- 当期需求可用上期家庭收入+本期允许动用的既有储蓄；更新后收入写入下期预算。
- 进口/出口需要有外部节点钱包或external_account，不能凭空销账。
- 各主体现金不足时：缩减订单/贷款/欠付记账，不允许账户凭空穿透到无限负值。

  def simulate_month(state, external_market, seed):
      rng = seeded_rng(seed, state.month)
      work = snapshot(state)
      finished = complete_buildings_and_apply_old_policies(work)
      network = calc_road_shortest_paths(work.map)
      labor = match_workers(work.firms, work.population, network)
      goods = prepare_inputs_and_compute_capacity(work, labor, external_market)
      budgets = create_household_budgets_from_previous_month(work.households)
      orders = allocate_household_orders(budgets, goods, network)
      orders += allocate_business_and_capital_orders(work, goods)
      orders += allocate_public_orders(work, goods)
      orders += allocate_external_orders(work, external_market)
      accepted_orders = clear_market_with_capacity_and_stocks(orders, goods)
      txs = create_transactions_once(accepted_orders)
      txs += create_wages_rents_taxes_welfare_dividends_interest(work)
      ledgers = settle_transactions_atomic(txs)
      report = compile_month_report(ledgers, work)
      assert_abs(report.local_cash_delta - report.external_net_flow) <= 0.01
      next_state = update_prices_wages_firms_population_education_faith(work, report)
      return next_state, report, txs, events

关卡式平衡测试（建议用同一随机种子重复模拟5年）：
A 正常基准：城市应可维持总体温和增长；财政不会首月无故暴涨。
B 加征利润税：当月政府收入可能上升，随后投资/企业数量受影响。
C 道路改善：通勤/物流成本下降；客流重新分配；新增利润并非凭空加成。
D 学校扩建：短期公共支出上升，12个月后技能供给逐步改善。
E 魔物强袭：工厂停工、货运损失，工资及财税下降；驻地缓解损失。
F 传教严格限制：信徒比例逐年下降；教会捐赠/低工资容忍趋弱，
  免税比例/宗教活动工时损失也趋弱；调整时可能出现短期社会不满。
G 进口煤炭中断：关键产业减产，不允许没煤照常生产。
H 需求衰退：订单下降、利润降低、商户退出、失业升高、税基收缩。
I 地产繁荣：住房开发增多、租金与地价变化，但须有现金融资和真实住户。
J 仅提高商品标价：如预算不增加，应产生销量变化，不能保证营业额无限增长。

15. 容易写错的开发警告
======================================================================

(1) “销售额340000”不等于“城市新产值340000”，本地中间交易有86000。
(2) 住房租金既是租户支出又是房东收入，不能凭空算成全城对外进账。
(3) 市政府支付工资进入居民收入，但不会改变全市总现金，属于内部转账。
(4) 企业折旧影响利润和净资产，不是本月再支付一笔现金。
(5) 企业设备投资是买家现金流出，也是本地卖家收入；必须有对应交易。
(6) 公共资本建设1500已在营业额构成中，不能又创建一笔“建设税收收入”。
(7) 公司税从税前利润征；分红来自税后利润，个人所得税再从居民股息征，
    这是两个合法且不同的税基，不是同一对象双重扣款Bug。
(8) 家庭必须从本月已有的钱消费；不能根据当月预计商业收入即时生成购买力。
(9) 信徒比例不是政策数值；政策改变传播速率，社会结构变化需要时间。
(10) “魔法师越多”的价值取决于魔物威胁：安全城市不会因堆驻地无限赚钱。
(11) 商户受客流、价格、工人、原料、物业租金共同影响，不是道路一个因子统治经济。
(12) 城际贸易的出口、游客和中央拨款是对外流入；本市居民在本市消费不是。
(13) 财政贷款融资现金与经营收入分开，偿还本金与利息分开。
(14) 经济数据必须带月份、单位、来源，不接受只有某个“繁荣指数”没有收支分解。
(15) 初始账本对账=游戏引擎正确性的硬门槛；调参只能显式改模型/参数，
     不能直接强行把最终财政或利润刷成想要的数字。

此架空世界不套用某一年英国真实工资或货币兑换，但借用“工业化社会早期的低收入、

阶层、工业及商业家庭而低于低收入家庭。上述比例是游戏起点，不是通用历史常数。
