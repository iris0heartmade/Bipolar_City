# 经济实验室反馈模型实施计划

目标：让实验室在繁荣与危机中均产生可对账、可解释、可复测的演化。

## 目录
1. 模块
2. 实施步骤
3. 验收

## 1. 模块
- model_ledger.py：复用统一清算，保留兼容 Ledger 接口，支持细分钱包与义务缺口。
- model_engine.py：装配分群/行业/资源状态。
- model_market.py：预算、供需、采购、物资与实际成交。
- model_dynamics.py：投资退出、工资价格、教育人口。
- model_sim.py：调度、公共与居民结算、月报和断言。
- data/economy：反馈参数与可重放场景。
- tools/economy_scenarios.py：批量场景报告与图表。
- tests/economy/test_model_feedback.py：会计、身份、资源、正负反馈及场景测试。

## 2. 实施步骤
1. 添加会复现审查错误的测试并执行，确认失败。
2. 接入细分账户与既有 Settlement，实际付款决定收入，修复首月与报表。
3. 接入有资金的投资与实际资源、岗位，完善企业破产/外逃与欠付。
4. 接入工资锚、价格、迁徙、分层与教育、有限救济，逐场景验证。
5. 更新实验室风险展示和场景执行入口，输出报告、场景原始数据和曲线。
6. 执行全量测试、120/240个月压力测试，记录实际结果与局限，更新中文日志。

## 3. 验收
测试以真实流水核算为准。先运行新增回归测试观察失败，再运行同一测试确认修复；最后执行全量测试与场景命令。对于旧测试中“默认工资必然下跌”等错误预期，改为设计要求的基准锚与工资上限测试并注明理由。
